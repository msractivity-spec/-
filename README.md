# 太陽光・蓄電池シミュレーター

UA値・C値・地域・屋根勾配・家族構成・電力プランなどから、太陽光発電と蓄電池の導入効果を
1時間単位（年間8,760時間）で試算するWebアプリです。

- 計算はすべてブラウザ内で行います（サーバー・データベース不要）
- 保存したプランは各端末のブラウザに保存されます（「書き出し／読み込み」で他端末へ移せます）
- スマホのホーム画面に追加するとアプリのように使えます

## 公開手順（Vercel）

1. https://vercel.com で「Add New…」→「Project」
2. このリポジトリを選んで「Import」
3. Framework Preset が **Next.js** になっていることを確認（環境変数は不要）
4. 「Deploy」を押すと公開URLが発行されます

## ローカルで動かす

```bash
npm install
npm run dev
```

ブラウザで http://localhost:3000 を開きます。

## 構成

| パス | 内容 |
|---|---|
| `lib/solar/engine.ts` | 計算エンジン（日射・発電・熱負荷・給湯・蓄電池・料金・収支） |
| `lib/solar/climate.ts` | 地点別の気象データ（月別気温・日射量・積雪損失） |
| `lib/solar/types.ts` | 入力項目の型・初期値・電力プランのひな型 |
| `components/solar/` | 入力画面・結果画面・グラフ |
| `app/page.tsx` | 画面全体（保存・比較・印刷） |

## 注意

電力プランの単価・売電単価・再エネ賦課金・気象データの初期値は目安です。最新の情報に修正してご利用ください。
